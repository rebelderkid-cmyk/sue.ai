# How to Transfer 175GB from Hugging Face to Google Cloud (The "Cloud Bridge" Method)

This guide explains how to move the `open-law-data-thailand` dataset directly to your Google Cloud Storage (GCS) without touching your local machine's disk or internet bandwidth.

## The Strategy
Instead of `HF -> Your PC -> GCS` (which is slow and fills your disk), we use:
`HF -> Temporary Cloud VM -> GCS`

We spin up a powerful Google Cloud VM (Worker), tell it to pull the data from Hugging Face at data-center speeds (often 1GB/s+), push it to your Storage Bucket, and then shut down.

## Prerequisites
1. **Google Cloud Project**: You must have a project selected in your CLI.
2. **GCS Bucket**: You need a bucket to store the files.
   - If you don't have one: `gsutil mb -l asia-southeast1 gs://your-unique-bucket-name`
3. **Quotas**: Ensure your project has quota for ~500GB of Persistent Disk (Standard or Balanced).

## Steps to Execute

### 1. Open your Terminal
Navigate to the folder where the script is located:
```bash
cd "/Users/rinne/Documents/Deka Scraping/Phase6_Cloud_Migration"
```

### 2. Make the script executable
```bash
chmod +x migrate_hf_to_gcp.sh
```

### 3. Run the "Job"
Replace `my-legal-bucket-name` with your actual GCS bucket name.
```bash
./migrate_hf_to_gcp.sh my-legal-bucket-name
```

### 4. Monitor
The script will exit almost immediately after creating the VM. The *actual work* happens on that remote VM.
To check on it, run the command the script gave you, or check the Google Cloud Console > Compute Engine.

To see the logs live:
```bash
gcloud compute instances get-serial-port-output hf-transfer-worker-XXXX --zone=asia-southeast1-b --on-host-change=TRUE
```
*(Replace `XXXX` with the timestamp suffix generated by the script)*

### 5. Cleanup
Once the logs say `[SUCCESS] Transfer Complete` and the instance status is `TERMINATED` (Stopped):
1. Check your bucket: `gsutil ls gs://my-legal-bucket-name/raw_data/`
2. **Delete the VM** to stop paying for the disk:
   ```bash
   gcloud compute instances delete hf-transfer-worker-XXXX --zone=asia-southeast1-b
   ```

## Cost Estimation
- **VM (e2-standard-4)**: ~$0.20 per hour.
- **Disk (500GB)**: ~$0.04 per hour.
- **Network**: Ingress from HF is free. Egress to GCS (same region) is free.
- **Total**: For a 3-hour job, it will cost less than **$1 USD**.
